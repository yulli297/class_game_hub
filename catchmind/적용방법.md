# 스케치북 캐치마인드 적용 방법

친구가 그리는 그림을 보고 제시어를 맞히는 실시간 그림 퀴즈예요.
선생님마다 **반 이름**(예: `천곡64`)으로 자기 반 게임 방을 열어요. 여러 반, 여러 학교가 같은 주소를 동시에 써도 서로 섞이지 않아요.

- 교사 화면은 선생님들끼리 공유하는 **교사 접속 비밀번호**를 알아야 들어갈 수 있어요. (초성 퀴즈·카드게임과 같은 비밀번호)
- 학생은 **QR 코드**를 찍거나 학생 주소에서 **반을 찾아** 누르고, 선생님이 정한 **학급 비밀번호**와 **이름**을 입력해 들어와요.

---

## 0. 파일 구성

```
catchmind/
├── app.js          (서버: 반·게임 진행)
├── words.js        (랜덤 제시어 5개 주제 125개)
├── 적용방법.md
└── public/
    ├── index.html  (학생 화면)
    ├── teacher.html(교사 화면 + 관리자)
    ├── canvas.js   (그림 그리기, 두 화면 공용)
    └── style.css   (크림·우드 스케치북 디자인)
```

이 폴더는 **수업 게임 모음 서버(class-game-hub)** 안에 들어가요. Render 설정과 환경변수는 저장소 맨 위 `README.md`를 보세요.

---

## 1. Render 환경변수

| Key | 꼭 필요? | 설명 |
|---|---|---|
| `TEACHER_PASSWORD` | **필수** | 교사 화면 공통 접속 비밀번호. 저장소가 공개라서 코드에는 적지 않고 Render에만 넣어요. 없으면 아무도 교사 화면에 들어갈 수 없어요 |
| `ADMIN_PASSWORD` | 추천 | 관리자 비밀번호. 교사 화면 아래 **관리자** 칸에서 열려 있는 모든 반을 보고 닫을 수 있어요 |

두 값 모두 초성 퀴즈·카드게임과 같이 써요. 이미 넣어 두셨다면 더 넣을 것이 없어요.

## 2. 주소

- 학생 화면: `https://내주소.onrender.com/catchmind/`
- 교사 화면: `https://내주소.onrender.com/catchmind/teacher` (학생 화면 왼쪽 아래 **교사모드**로도 들어가요)

### 비밀번호 정리

| 비밀번호 | 누가 정하나 | 누가 아나 | 어디에 쓰나 |
|---|---|---|---|
| 교사 접속 비밀번호 | 관리자 (Render `TEACHER_PASSWORD`) | 선생님들 | 교사 화면에 들어갈 때 (기기에 기억돼요) |
| 학급 관리 비밀번호 (교사용) | 반을 만든 선생님 | 그 선생님만 | 다른 기기에서 자기 반을 관리할 때 |
| 학급 비밀번호 | 반을 만든 선생님 | 그 반 학생들 | 학생이 반에 들어갈 때 (태블릿에 기억돼요) |
| 관리자 비밀번호 | 관리자 (Render `ADMIN_PASSWORD`) | 관리자만 | 모든 반 보기·닫기 |

학생은 반을 먼저 고르기 때문에 **다른 반과 학급 비밀번호가 같아도 괜찮아요.**

---

## 3. 수업 진행 순서

1. **서버 깨우기**: Render 무료 서버는 15분 동안 아무도 안 쓰면 잠들어요. 수업 5분 전에 교사 화면을 열어 두세요.
2. **반 만들기**: 교사 화면 → 교사 접속 비밀번호 → **새 반 만들기** → 반 이름(띄어쓰기 없이 2~12자), 학급 비밀번호, 학급 관리 비밀번호
3. **게임 설정** (대기실 왼쪽, 바꾸면 바로 저장돼요)
   - 라운드 제한 시간: 45 / 60 / 90 / 120초
   - 제시어: 랜덤(주제 고르기 + 라운드 수) 또는 선생님 직접 입력(쉼표·줄바꿈으로 구분, 입력한 순서대로, 개수 = 라운드 수)
4. **QR 크게 보기**를 눌러 칠판 화면에 띄워요 → 학생들이 찍고 학급 비밀번호·이름 입력
5. 모두 들어오면 **게임 시작하기**
6. 라운드마다: 화가 발표(3초) → 그리기·맞히기 → 결과(5초) → 다음 라운드
7. 끝나면 최종 순위 → **같은 설정으로 다시 하기** 또는 **대기실로(설정 바꾸기)**

---

## 4. 교사 화면 버튼

| 버튼 | 하는 일 |
|---|---|
| 제시어 `보기` / `가리기` | 제시어는 **처음에 가려져 있어요** (TV에 교사 화면을 띄워도 안 보이게). 필요할 때만 눌러서 확인 |
| 그림 전체 지우기 | 화가 그림을 모두 지워요 |
| 라운드 스킵 | 이번 라운드를 넘겨요 (화가 점수 없음) |
| 게임 끝내기 | 바로 최종 순위로 |
| 이름 옆 × | 학생을 반에서 내보내요 |
| 학급 비밀번호 `바꾸기` | 이미 들어온 학생은 그대로, 새로 들어오는 학생부터 적용 |
| 반 나가기 | **이 기기에서만** 관리를 그만해요. 반과 게임은 그대로 |
| 반 닫기 | 반을 없애요. 학생들도 모두 나가게 돼요 |

교실 컴퓨터와 태블릿처럼 **교사 기기 여러 대**로 같은 반을 함께 볼 수 있어요.

---

## 5. 게임 규칙

- 화가는 접속한 학생 중에서 무작위로 정하고, 모두 한 번씩 할 때까지 겹치지 않아요. (다시 하기를 해도 이어서 돌아가요)
- 맞히면 **빨리 맞힐수록 높은 점수** (100~500점). 띄어쓰기는 무시해요.
- 한 명이라도 맞히면 **화가 +400점**
- 틀리면 5초 뒤에 다시 낼 수 있어요.
- **전원 정답**: 지금 라운드에 접속해 있는 학생(화가 빼고)이 모두 맞히면 바로 끝나요. 강퇴하거나 나간 학생은 빠지고, 중간에 들어온 학생은 들어가요.

### 접속이 끊길 때

- **같은 이름으로 다시 들어오면 원래 학생으로 이어져요** (점수·이번 라운드 정답 기록 그대로). 새로고침하거나 와이파이가 잠깐 끊기면 태블릿이 기억한 반·비밀번호·이름으로 **자동으로** 다시 들어가요.
- 다른 기기에서 접속 중인 이름과 똑같은 이름으로는 들어올 수 없어요 (동명이인은 성까지 넣기).
- **화가가 끊기면** 15초 기다렸다가 안 돌아오면 다음 라운드로 넘어가요.
- 그리는 중에 **맞힐 친구가 아무도 없으면** 15초 뒤 라운드를 끝내요.
- 게임 중에 **학생이 2명보다 적어지면** 60초 기다렸다가, 다시 모이면 이어서 하고 아니면 게임을 마쳐요.
- 대기실에서 끊긴 학생은 60초 동안 명단에 (자리비움)으로 남아 있어요.

---

## 6. 서버 아끼기 (자동으로 돼요)

- **15분 동안 화면을 누르지 않은 기기는 서버 접속을 완전히 끊어요.** 자동으로 다시 붙지 않고, `다시 들어가기`를 누르면 같은 이름으로 이어져요.
  게임이 진행 중일 때는 게임을 쓰고 있는 것으로 보고 끊지 않아요 (교사 화면을 띄워 놓고 구경만 해도 괜찮아요).
- 아무도 접속하지 않은 채 **1시간**이 지난 반은 자동으로 닫혀요.
- 서버가 다시 켜지면(잠들었다 깨거나 재배포) 반이 모두 사라져요. 교사 화면에 안내가 뜨면 같은 이름으로 다시 만들면 돼요. 학생 화면도 반 목록으로 돌아가요.

---

## 7. 숫자를 바꾸고 싶을 때

`app.js` 위쪽 `CONFIG` 숫자만 바꾸면 돼요.

| 항목 | 지금 값 | 의미 |
|---|---|---|
| `IDLE_MS` | 15분 | 안 쓰는 기기 접속 끊기 |
| `CLASS_IDLE_MS` | 1시간 | 아무도 없는 반 닫기 |
| `DRAWER_GRACE_MS` | 15초 | 끊긴 화가를 기다리는 시간 |
| `WAIT_PLAYERS_MS` | 60초 | 학생이 2명보다 적을 때 기다리는 시간 |
| `DRAWER_SCORE` | 400 | 화가 점수 |
| `MAX_STUDENTS` | 40 | 한 반 최대 학생 수 |
| `MAX_CLASSES` | 60 | 동시에 열 수 있는 반 수 |

제시어는 `words.js`에서 주제별로 고치거나 더할 수 있어요.
