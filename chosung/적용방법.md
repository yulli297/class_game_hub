# 초성 퀴즈 적용 방법 (개인전 + 모둠 대항전 통합판)

선생님마다 **반 이름**(예: `천곡64`)으로 자기 반 게임 방을 열어요.
여러 반, 여러 학교가 같은 주소를 동시에 써도 서로 섞이지 않아요.

- 교사 화면은 선생님들끼리 공유하는 **교사 접속 비밀번호**를 알아야 들어갈 수 있어요.
- 학생은 **QR 코드**를 찍거나 학생 주소에서 **반을 찾아** 누르고, 선생님이 정한 **학급 비밀번호**를 입력해 들어와요.

- **개인전**: 학생 1인 1기기, 자기 번호로 입장 → 최대 6개 방으로 자동 배정
- **모둠 대항전**: 모둠당 1기기, 모둠 번호(1~6)로 입장 → 모든 모둠이 한 방에서 대결
- **정답 인정 범위**: 전체 단어 / 고유어만 / 한자어만 (두 게임 모두 고를 수 있어요)

## 1. Render 환경변수

> 이 게임은 **수업 게임 모음 서버(class-game-hub)** 안에 들어 있어요. Render 설정(Build/Start Command, 환경변수 전체)은 저장소 맨 위 `README.md`를 보세요.

Render 대시보드 → 서비스 → **Environment**에서 넣어요. 넣거나 바꾸면 서버가 자동으로 다시 켜져요.

| Key | 꼭 필요? | 설명 |
|---|---|---|
| `STDICT_KEY` | **필수** | 표준국어대사전 오픈 API 키. 정답 판정과 뜻, 고유어·한자어 판정에 써요 |
| `OPENDICT_KEY` | 선택 | 우리말샘 키. 표준국어대사전이 먹통일 때 비상용 (전체 단어 범위에서만) |
| `TEACHER_PASSWORD` | **필수** | 교사 화면 공통 접속 비밀번호 (선생님들끼리만 공유하는 값). 저장소가 공개라서 코드나 이 문서에는 적지 않고 Render에만 넣어요. 없으면 아무도 교사 화면에 들어갈 수 없어요 |
| `ADMIN_PASSWORD` | 추천 | 관리자 비밀번호 (나만 아는 값). 교사 화면 아래 **관리자** 칸에서 열려 있는 모든 반을 보고 닫을 수 있어요. 비워 두면 관리자 칸이 안 보여요 |

※ 예전 초성 퀴즈 서버(저장소 `-`)의 `STDICT_KEY`, `OPENDICT_KEY`와 같은 키를 그대로 쓰면 돼요.

## 2. 주소

- 학생 화면: `https://내주소.onrender.com/chosung/` (첫 화면 `https://내주소.onrender.com`에서 골라 들어와도 돼요)
- 교사 화면: `https://내주소.onrender.com/chosung/teacher` (학생들에게는 알려주지 마세요. 첫 화면 왼쪽 아래 **교사모드**로도 들어가요)

다른 선생님께 공유할 때는 이 두 주소와 교사 접속 비밀번호를 알려 드리면 돼요. 각자 자기 반 이름으로 반을 만들어 써요.

### 비밀번호 정리

| 비밀번호 | 누가 정하나 | 누가 아나 | 어디에 쓰나 |
|---|---|---|---|
| 교사 접속 비밀번호 | 관리자 (Render 환경변수 `TEACHER_PASSWORD`) | 선생님들 | 교사 화면에 들어갈 때 (기기에 기억돼요) |
| 학급 관리 비밀번호 (교사용) | 반을 만든 선생님 | 그 선생님만 | 다른 기기에서 자기 반을 관리할 때 |
| 학급 비밀번호 | 반을 만든 선생님 | 그 반 학생들 | 학생이 반에 들어갈 때 (태블릿에 기억돼요) |
| 관리자 비밀번호 | 관리자 (Render 환경변수 `ADMIN_PASSWORD`) | 관리자만 | 모든 반 보기·닫기 |

## 3. 수업 전 점검

1. **서버 깨우기**: Render 무료 서버는 15분 동안 아무도 안 쓰면 잠들어요. 수업 5분 전에 교사 화면을 한 번 열어 두세요. 처음 열 때 1분 정도 걸릴 수 있어요.
2. **반 만들기**: 교사 화면 → 교사 접속 비밀번호 입력 → **새 반 만들기** → 반 이름(띄어쓰기 없이 한글·영문·숫자 2~12자), 학급 비밀번호(학생용, 예: 숫자 4자리), 학급 관리 비밀번호(교사용) 입력
3. **사전 연결 테스트**: 대기실의 `사전 연결 테스트` 버튼 → ✅가 나오는지 확인 (고유어·한자어 판정도 함께 시험해요)

## 4. 수업 진행 순서

1. 교사 화면에서 **게임 종류**(개인전 / 모둠 대항전)와 **정답 인정 범위**(전체 / 고유어 / 한자어)를 골라요
2. 1~5라운드 초성 입력 (입력하면 자동 저장돼요)
3. 대기실 오른쪽 위의 **QR 크게 보기**를 눌러 칠판 화면에 띄워요 (QR 코드 + 반 이름 + 학급 비밀번호가 크게 나와요. 화면을 누르면 닫혀요)
4. 학생 입장
   - **QR 코드를 찍으면** 우리 반이 바로 골라져서 학급 비밀번호만 입력하면 돼요
   - **직접 학생 주소로 들어오면** 열린 반 목록에서 우리 반을 찾아 누르고(검색 가능) 학급 비밀번호 입력
   - 그다음 **번호(모둠 번호)** 입력. 반과 학급 비밀번호는 태블릿이 기억해서 다음부터는 바로 번호 입력 화면이 나와요
5. 교사 화면 숫자판으로 모두 들어왔는지 확인 → **게임 시작**
6. 5초 카운트 → 1라운드 시작. 교사 화면에서 진행 상황 확인 (개인전은 방마다 CCTV, 모둠전은 큰 화면 하나)
7. 라운드가 끝나면 상단 **다음 라운드 시작** (옆에 다음 초성이 미리 보여요)
8. 5라운드가 끝나면 결과 화면 → 다시 하려면 **새 게임 준비**

**게임 종류를 바꾸면** 번호 체계(1~30번 ↔ 1~6모둠)가 달라서 들어와 있던 학생들은 다시 입장해야 해요. 학생 화면에 안내가 떠요.

## 5. 교사 화면 버튼

| 버튼 | 하는 일 |
|---|---|
| 반 나가기 | **이 기기에서만** 반 관리를 그만해요. 반과 게임은 그대로예요. 비밀번호로 다시 들어올 수 있어요 |
| 반 닫기 | 반을 없애요. 학생들도 모두 나가게 돼요 |
| 학급 비밀번호 바꾸기 | 대기실 안내 칸의 `바꾸기`. 이미 들어온 학생은 그대로, 새로 들어오는 학생부터 적용 |
| 우리 반 들어가기 | 이미 만든 반을 다른 기기(교실 컴퓨터 ↔ 태블릿)에서 관리할 때 |

## 6. 게임 규칙 요약

| | 개인전 | 모둠 대항전 |
|---|---|---|
| 입장 | 학생 번호 1~30 | 모둠 번호 1~6 |
| 방 | 인원에 맞춰 최대 6개 방 랜덤 배정 | 모든 모둠이 한 방 |
| 제한시간 | 1인 10초 | 1모둠 15초 (의논 시간 포함) |
| 라운드 종료 | 아무도 안 틀리고 4바퀴 | 아무도 안 틀리고 6바퀴 |
| 뜻 팝업 | 3초 | 3.5초 |
| 결과 | 방별 생존 여부 | 모둠 순위 (생존 > 탈락 적은 순 > 맞힌 단어 많은 순) |

공통 규칙
- 라운드마다 순서를 랜덤으로 섞음. 제한시간 안에 못 쓰면 라운드 탈락 1회, 2회면 패배
- 틀린 단어는 제한시간 안에 계속 다시 쓸 수 있음 (사전 확인 중에는 시간이 멈춤)
- 같은 방에서 이미 나온 단어는 "이미 제출된 정답입니다."
- 표준국어대사전에 있는 단어만 인정 (방언·북한어·옛말·지역어 제외)
- 고유어/한자어만 고르면 그 종류의 단어만 정답. 다른 종류면 "○○은(는) 고유어가 아니에요" 처럼 안내
- 사전 연결이 실패해도 게임은 끝나지 않음: 시간을 멈춘 채 "같은 단어를 다시 제출해 주세요" 안내 (교사 화면 위쪽에 실패 횟수 표시)
- 접속이 끊긴 학생(모둠) 차례는 건너뜀. 자기 차례에 잠깐 끊겨도 제한시간 안에 돌아오면 이어서 답할 수 있음
- 대기실에서 잠깐 끊긴 학생은 60초 동안 명단에 남아 있음 (교사 화면에 노란 점선)
- 한 번 확인한 단어는 서버가 기억해서 다시 사전에 묻지 않음 (모든 반이 함께 써서 사전 호출 수가 줄어요)

## 7. 무료 서버 시간 아끼기 (자동으로 돼요)

- 학생 화면은 **20분**, 교사 화면은 **30분** 동안 아무것도 누르지 않으면 서버 연결을 쉬어요. 화면을 누르면 바로 다시 연결돼요.
  → 누가 탭을 켜 둔 채 퇴근해도 서버가 밤새 깨어 있지 않아요. (학생이 참가한 라운드가 진행 중일 때는 끊지 않아요)
- 아무도 접속하지 않은 채 **1시간**이 지난 반은 자동으로 닫혀요. (5분마다 확인해서 실제로는 1시간~1시간 5분 사이에 닫혀요)
- 서버가 다시 켜지면(잠들었다 깨거나 코드 수정 후 재배포) 반이 모두 사라져요. 교사 화면에 안내가 뜨면 같은 이름으로 다시 만들면 돼요.

## 8. 규칙 숫자를 바꾸고 싶을 때

`server.js` 위쪽의 `RULES`(게임 종류별)와 `CONFIG`(공통) 숫자만 바꾸면 돼요. 직접 고치기 어려우시면 말씀해 주세요.

| 항목 | 지금 값 | 의미 |
|---|---|---|
| `RULES.solo.maxNum` | 30 | 개인전 최대 번호 |
| `RULES.solo.turnMs` / `RULES.team.turnMs` | 10000 / 15000 | 제한시간 (1000 = 1초) |
| `RULES.solo.laps` / `RULES.team.laps` | 4 / 6 | 몇 바퀴 돌면 라운드 종료 |
| `CONFIG.TOTAL_ROUNDS` | 5 | 전체 라운드 수 |
| `CONFIG.LOSS_LIMIT` | 2 | 몇 번 탈락하면 패배 |
| `CONFIG.MAX_CLASSES` | 60 | 동시에 열 수 있는 반 수 |
| `CONFIG.CLASS_IDLE_MS` | 1시간 | 아무도 없는 반을 닫기까지 시간 |

## 9. 문제가 생기면

- **반 목록에 우리 반이 없어요 / "그런 반이 없어요"**: 아직 반을 안 만들었거나, 1시간 동안 아무도 없어서 자동으로 닫혔거나, 서버가 다시 켜져서 반이 사라진 경우예요. 교사 화면에서 반을 다시 만들어 주세요. (QR 코드는 반 이름으로 만들어져서, 같은 이름으로 다시 만들면 예전에 인쇄한 QR도 그대로 쓸 수 있어요)
- **"접속 비밀번호가 맞지 않아요"**: Render 환경변수 `TEACHER_PASSWORD` 값을 확인해 주세요. 값을 바꾸면 선생님들 기기에 기억된 비밀번호도 다시 물어봐요.
- **"학급 비밀번호가 맞지 않아요"**: 교사 화면 대기실 안내 칸에서 학급 비밀번호를 확인해 주세요.
- **"이미 열려 있는 반 이름이에요"**: 다른 선생님이 같은 이름을 쓰는 중이에요. 우리 반이면 「우리 반 들어가기」로, 아니면 학교 이름을 붙여서(예: 천곡초64) 만들어 주세요.
- **"이미 접속 중인 번호예요"**: 다른 학생이 그 번호로 들어와 있는 경우예요. 같은 태블릿에서 새로고침한 경우에는 그대로 다시 들어가져요.
- **학생이 번호를 잘못 넣었을 때**: 대기 화면의 `번호 바꾸기`(게임 시작 전에만), 반을 잘못 들어갔을 때는 번호 입력 화면의 `반 바꾸기`.
- **빨간 "연결이 끊겼어요" 띠**: 와이파이가 끊긴 거예요. 기다리면 저절로 다시 들어가요. 오래 안 되면 새로고침하세요(반과 번호는 기억돼요).
- **게임 중 멈춘 것 같을 때**: 교사 화면의 `게임 끝내기` → `새 게임 준비`.
