# 던전 카드 모험 — 6학년 수학 카드 대전 (여러 선생님 공용)

문제를 풀 때마다 카드 3장 중 1장을 골라 18장 덱을 만들고, 친구와 1:1로 대결해요.
선생님마다 **반 이름**(예: `천곡64`)으로 자기 반을 열고, **문제로 낼 단원**을 골라요.
여러 반, 여러 학교가 같은 주소를 동시에 써도 서로 섞이지 않아요.

---

## 1. Render 환경변수

Render 대시보드 → 서비스 → **Environment**에서 넣어요.

| Key | 꼭 필요? | 설명 |
|---|---|---|
| `TEACHER_PASSWORD` | **필수** | 교사 화면 공통 접속 비밀번호 (선생님들끼리만 공유). 저장소가 공개라서 코드에는 적지 않아요. 없으면 아무도 교사 화면에 들어갈 수 없어요 |
| `ADMIN_PASSWORD` | 추천 | 관리자 비밀번호 (나만 아는 값). 교사 화면의 **관리자** 칸에서 열린 반을 모두 보고 닫을 수 있어요 |

Build Command는 `npm install`, Start Command는 `npm start`예요.

---

## 2. 주소

- 학생 화면: `https://내주소.onrender.com`
- 교사 화면: `https://내주소.onrender.com/teacher` (학생들에게는 알려주지 마세요)

| 비밀번호 | 누가 정하나 | 누가 아나 | 어디에 쓰나 |
|---|---|---|---|
| 교사 접속 비밀번호 | 관리자 (`TEACHER_PASSWORD`) | 선생님들 | 교사 화면에 들어갈 때 (기기에 기억돼요) |
| 학급 관리 비밀번호 (교사용) | 반을 만든 선생님 | 그 선생님만 | 다른 기기에서 자기 반을 관리할 때 |
| 학급 비밀번호 | 반을 만든 선생님 | 그 반 학생들 | 학생이 반에 들어갈 때 (태블릿에 기억돼요) |
| 관리자 비밀번호 | 관리자 (`ADMIN_PASSWORD`) | 관리자만 | 모든 반 보기·닫기 |

## 3. 수업 진행

1. 수업 몇 분 전에 교사 화면을 열어 서버를 깨워 두세요. (무료 서버는 처음 열 때 1분쯤 걸릴 수 있어요)
2. 교사 화면 → 교사 접속 비밀번호 → **새 반 만들기**: 반 이름, 학생 수, 학급 비밀번호(학생용), 학급 관리 비밀번호(교사용), **단원**(여러 개 고르면 섞여서 나와요), 진행 방식(문제 모드 / 게임 모드)
3. **QR 크게 보기**를 칠판 화면에 띄워요. 학생은 QR을 찍거나 학생 주소에서 반을 찾아 학급 비밀번호 → 번호를 눌러 들어와요.
4. 학생: **모험 시작** → 안내 4쪽(진행 방법 · 공격 카드 · 방어 카드 · 특수 카드) → 문제 풀고 카드 고르기 12번
   - 틀리면 같은 문제를 다시 풀어요. 5번 연속으로 틀리면 남은 칸이 가뭄 카드로 채워져요.
5. 18장이 모이면 **대결 찾기** → 접속한 학생이 모두 대기열에 들어오면 무작위 대결 (홀수면 한 명은 연습 로봇)
   - 오래 기다리게 되면 교사 화면의 **지금 대기 중인 학생끼리 매칭**을 누르세요.
6. 대결이 끝나면 카드 5장을 계승하고, 7문제를 더 풀어 다시 18장을 채워요.

수업 중에도 교사 화면에서 **단원**과 **진행 방식**을 바꿀 수 있어요. (모은 카드와 기록은 그대로)

## 4. 알아 두실 점

- 기록은 서버 메모리에만 있어요. 서버가 다시 켜지면(잠들었다 깨거나 재배포) 반이 사라지니, 같은 이름으로 다시 만들면 돼요. 같은 이름이면 예전에 인쇄한 QR도 그대로 쓸 수 있어요.
- 아무도 접속하지 않은 채 **1시간**이 지난 반은 자동으로 닫혀요.
- 학생 화면은 20분, 교사 화면은 30분 동안 아무것도 누르지 않으면 서버 연결을 쉬어요. 화면을 누르면 다시 연결돼요. (대결 중에는 끊지 않아요)
- 단원 문제는 `game/units/` 폴더에 단원마다 파일 하나씩 있어요. 단원 목록은 `game/units/index.js`, 여러 단원이 같이 쓰는 계산·그림·채점 도구는 `game/units/_common.js`예요.
- 6학년 1·2학기 12개 단원이 모두 들어 있어요. 단원마다 7가지 유형의 기초·기본 문제가 자동으로 만들어지고, 문제 화면에는 그림과 연습장이 함께 나와요.
- 분수로 답하는 문제는 자연수·분자·분모 칸에 써요. 기약분수로 써야 정답이고, 가분수와 대분수는 둘 다 정답이에요.
- 숫자로 답할 때 단위(cm, %, 개 등)를 같이 써도 정답으로 인정해요.
- 카드 수치와 설정(HP, MP, 턴 시간)은 `game/cards.js`에서 바꿀 수 있어요.
