# 수업 게임 모음 (class-game-hub)

서버 하나에 수업용 게임 세 개를 함께 열어요. 여러 선생님, 여러 학교가 같은 주소를 동시에 써도 반마다 따로 돌아가요.

| 주소 | 게임 | 교사 화면 |
|---|---|---|
| `https://내주소.onrender.com/` | 게임 고르는 첫 화면 (왼쪽 아래 **교사모드**) | |
| `https://내주소.onrender.com/card/` | **수학 카드 대전** — 6학년 수학 12개 단원 문제로 카드를 모아 1:1 대결 | `/card/teacher` |
| `https://내주소.onrender.com/chosung/` | **초성 퀴즈** — 개인전 · 모둠 대항전 | `/chosung/teacher` |
| `https://내주소.onrender.com/catchmind/` | **스케치북 캐치마인드** — 친구 그림 보고 제시어 맞히기 | `/catchmind/teacher` |

예전 카드게임 주소(`주소/?c=반이름`, `주소/teacher`)로 들어오면 자동으로 `/card/` 주소로 넘어가요. 그래서 예전에 인쇄한 카드게임 QR도 그대로 쓸 수 있어요.

---

## Render 설정

- **Build Command**: `npm install`
- **Start Command**: `npm start`

### 환경변수 (Render → 서비스 → Environment)

| Key | 꼭 필요? | 쓰는 게임 | 설명 |
|---|---|---|---|
| `TEACHER_PASSWORD` | **필수** | 모두 | 교사 화면 공통 접속 비밀번호 (선생님들끼리만 공유). 없으면 아무도 교사 화면에 들어갈 수 없어요 |
| `ADMIN_PASSWORD` | 추천 | 모두 | 관리자 비밀번호 (나만 사용). 교사 화면의 관리자 칸에서 열린 반을 모두 보고 닫을 수 있어요 |
| `STDICT_KEY` | **필수** (초성 퀴즈) | 초성 퀴즈 | 표준국어대사전 오픈 API 키. 정답 판정·뜻·고유어/한자어 판정 |
| `OPENDICT_KEY` | 선택 | 초성 퀴즈 | 우리말샘 키. 표준국어대사전이 먹통일 때만 비상용 |

저장소가 공개라서 비밀번호와 키는 코드에 적지 않고 Render에만 넣어요.

---

## 알아 두실 점

- 기록은 서버 메모리에만 있어요. 서버가 다시 켜지면(잠들었다 깨거나 재배포) **모든 게임의 열린 반이** 사라져요. 수업 중에는 배포하지 마세요.
- 아무도 접속하지 않은 채 1시간이 지난 반은 자동으로 닫혀요.
- Render 무료 서버는 15분 동안 아무도 안 쓰면 잠들어요. 수업 5분 전에 교사 화면을 한 번 열어 두세요.

## 폴더 구성

| 폴더·파일 | 내용 |
|---|---|
| `server.js` | 게임들을 하나로 묶는 서버 (주소 나누기, 실시간 연결 통로 나누기) |
| `public/` | 게임 고르는 첫 화면 |
| `card/` | 수학 카드 대전 (`card/적용방법.md`에 자세한 사용법) |
| `card/game/units/` | 6학년 수학 단원별 문제 만들기 |
| `chosung/` | 초성 퀴즈 (`chosung/적용방법.md`에 자세한 사용법) |
| `catchmind/` | 스케치북 캐치마인드 (`catchmind/적용방법.md`에 자세한 사용법) |
